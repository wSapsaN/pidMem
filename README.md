# pidMem

Маленькая утилита которая способна в момент вызова вывести приложение которое потребляет больше всего памяти.
Можно запустить в cron или systemctl таймер и перенаправить вывод в файл или файлы.

Приложение не имеет порог съедаемой памяти после которого должен срабатывать парсер и искать самое наглое приложение.
Это планируется сделать в ближайшем времени.
То есть можно сказать, что он ещё будет дорабатываться, но пока работает довольно просто.

# Build \ Сборка

В каталоге build есть файл build.sh, он исполняем, поэтому для сборки нужно его просто вызвать.

```bash
$ ./build.sh
```

Файл который соберется имеет название "app", его можно переименовать или сделать это в самом build.sh
